Quick install

  1. Blender → Edit → Preferences → Add-ons
  2. Click Install… and select the add-on ZIP
  3. Enable the add-on (checkbox)

Supported (current)

  • Build and manage an animation library (save/organize reusable motions).
  • Mixamo → Mixamo retargeting (same rig family).
  • MakeHuman → MakeHuman retargeting (same rig family).
  • Universal → Universal retargeting (same rig family).
  • Designed for known, clean rigs that match the expected profiles.

Not supported yet

  • Cross-rig retargeting between different rig types (e.g., Mixamo → Universal, Mixamo → MakeHuman, etc.).
  • Characters with unknown / unrecognized rig structures.
  • Meshes with major defects (broken weights, extreme proportions, missing bones, flipped orientation, etc.).
  • “Automatic fix everything” mode for badly imported or inconsistent rigs.

Note: support expands over time as new rig profiles and validation tools are added.
